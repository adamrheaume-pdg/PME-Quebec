PME Quebec 5.10.1 - GitHub Actions

1. Creez un depot GitHub vide nomme PME-Quebec.
2. Importez le contenu de ce ZIP a la racine du depot.
3. GitHub Actions demarre automatiquement sur main/master.
4. Ouvrez Actions > Build PME Quebec APK > dernier run.
5. Telechargez l'artifact PME-Quebec-5.10.1-Wyze-ARM64-debug.

Le workflow installe Java 17 et Android SDK, compile l'application et publie l'APK comme artifact.
