# Rabais Québec — vitrine de spéciaux

La page principale est conçue comme une vitrine de rabais. Chaque carte peut afficher : produit, enseigne, prix courant, prix régulier, économie, format, prix unitaire, période de validité, catégorie, image autorisée et lien source.

Les données factuelles (prix, format, dates, enseigne) peuvent être importées automatiquement depuis des sources autorisées. Les images et descriptions de tiers ne sont pas copiées en masse sans droit d'utilisation; le champ `imageUrl` est réservé aux images fournies par une source officielle/autorisée.
