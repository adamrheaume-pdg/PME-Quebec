# Playlist Québec — lecteur YouTube Android

Application Android distincte de PME Québec.

Fonctions :
- collage d'une liste de liens YouTube directs ;
- sauvegarde de plusieurs playlists sur l'appareil ;
- lecture séquentielle ou aléatoire ;
- précédent / suivant / pause ;
- répétition désactivée, playlist complète ou titre courant ;
- passage automatique au titre suivant ;
- lecteur YouTube intégré visible.

Les URL de recherche `youtube.com/results?search_query=...` ne sont pas des vidéos et ne peuvent donc pas être lues directement. Utiliser des liens `watch?v=`, `youtu.be`, `shorts/` ou `embed/`.
